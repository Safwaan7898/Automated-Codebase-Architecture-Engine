07 Appendix & Methodology
MATHEMATICAL FOUNDATIONS & AUDIT SETTINGS
Cycle Detection: Tarjan's Strongly Connected Components algorithm running in O(V + E) time complexity.
Community Clustering: Louvain heuristic modularity maximization across directed dependency edges.
Centrality & Blast Radius: Brandes betweenness centrality and PageRank power-iteration.
Instability Metrics: Robert C. Martin package coupling formula (Instability I = Ce / (Ca + Ce)).
Limitations: Dynamic imports, runtime reflection, and eval() are not statically resolved. Analysis is currently supported for Python and Java codebases only. Tests, sample fixtures, mocks, and third-party vendor directories (node_modules, site-packages, venv) are excluded by default.
